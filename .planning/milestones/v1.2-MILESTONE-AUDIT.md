### Integration Findings

**1. BLS registration requires registry in poaStore (Low severity)**
- **Affected:** BLS-03 (one-click registration)
- **File:** `app/src/pages/services/ServiceDetailPage.tsx`
- The "Register BLS Key" button only appears when `blsRegStatus === 'unregistered'`, which requires `checkBlsRegistrationStatus` to run, which requires `registry !== null` in poaStore. BLS services not added as POA registries will never show the button. This is defensively correct but undocumented.

**2. SignaturePrefix type drift (Low severity)**
- **Affected:** FND-01 (type system)
- **File:** `app/src/types/index.ts:211`
- `SignaturePrefix = 'eip191'` (union of one) vs `SubmitDraft.signaturePrefix: 'eip191' | 'none'` (inline). Runtime mapping in `buildSubmit` is correct. Latent type safety gap for future refactors.
