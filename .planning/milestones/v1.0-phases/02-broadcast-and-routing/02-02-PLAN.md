**CATCH-01 scope clarification:** The Engine's catch-up mechanism is pull-based (requires knowing digests to request via `mailbox.subscribe(digest)`). Implementing a full pull-based catch-up handler is out of scope for this phase. Instead, CATCH-01 is satisfied by push-based cached re-broadcast: the Engine caches broadcast messages per-peer (bounded by `deque_size`), and when a reconnecting peer establishes a connection, the Engine's internal relay delivers cached messages from connected peers' deques. This means missed messages are recovered when a subsequent broadcast occurs from the same or another peer, or when the Engine re-broadcasts cached content to the newly connected peer. This matches what the Engine actually provides without requiring application-level pull logic.

    **CRITICAL ARCHITECTURE:** Use the Two-Channel approach (Option A from research):
    - Channel 0 (engine_sender, engine_receiver): consumed by `Engine::start()` for caching + catch-up
    - Channel 1 (direct_sender, direct_receiver): read by a bridge task for real-time inbound forwarding

    **CATCH-01 SCOPE (push-based recovery):** The Engine caches broadcast messages in per-peer deques (bounded by `deque_size`). When a peer reconnects, the Engine's internal relay delivers cached messages from connected peers' deques to the newly connected peer. This is push-based -- the Engine automatically re-broadcasts cached content. No application-level pull mechanism (`mailbox.subscribe(digest)`) is needed. Missed messages are recovered when:
    - The Engine re-broadcasts cached content to the reconnecting peer
    - A subsequent broadcast from any peer triggers delivery of the cached messages
    Document this behavior in code comments where the Engine is configured.

    **ASYNC COMPATIBILITY RESOLUTION:** The `direct_receiver.recv()` from commonware_p2p::Receiver may NOT be compatible with `tokio::select!` (it runs in the commonware runtime, not Tokio). The concrete solution is:

    Spawn a dedicated task inside the commonware runtime that reads from `direct_receiver` and forwards via a `tokio::sync::mpsc` bridge channel to the bridge loop:
    ```rust
    // Create a Tokio mpsc channel to bridge commonware -> Tokio
    let (inbound_tx, mut inbound_rx) = tokio::sync::mpsc::channel::<(PublicKey, Vec<u8>)>(256);

    // Spawn a commonware task that reads from direct_receiver and sends to Tokio channel
    context.spawn("p2p_inbound_bridge", {
        let inbound_tx = inbound_tx.clone();
        async move {
            loop {
                match direct_receiver.recv().await {
                    Ok((peer_pubkey, raw_bytes)) => {
                        if inbound_tx.send((peer_pubkey, raw_bytes)).await.is_err() {
                            break; // Bridge loop shut down
                        }
                    }
                    Err(e) => {
                        tracing::error!("Direct receiver error: {:?}", e);
                        break;
                    }
                }
            }
        }
    });
    ```

    Then in the bridge loop, use `inbound_rx.recv()` which IS Tokio-native and works in `tokio::select!`.

       **CRITICAL: Application-level deduplication (BCAST-02).** The two-channel architecture means a message can arrive via both the Engine (channel 0) and the direct channel (channel 1).        ```rust

       ```rust
       let mut retry_queue = RetryQueue::new();
       // BCAST-02: Application-level deduplication by message digest.
       // The Engine deduplicates on channel 0 internally, but channel 1
       // (direct) has no built-in dedup. This set ensures exactly-once
       // delivery to the Aggregator regardless of channel.
       let mut seen_digests: HashSet<sha256::Digest> = HashSet::new();
       const MAX_SEEN_DIGESTS: usize = 1024;

       loop {
           tokio::select! {
               cmd = command_rx.recv() => {
                   // Placeholder: log commands, will be implemented in Task 2
                   match cmd {
                       Some(cmd) => {

                           tracing::info!("P2P command channel closed, shutting down");
                           context.stop(0, None).await.ok();
                           break;
                       }
                   }
               }
               msg = inbound_rx.recv() => {
                   match msg {
                       Some((peer_pubkey, raw_bytes)) => {
                           // Decode P2pMessage from raw bytes
                           let p2p_msg: P2pMessage = match commonware_codec::Decode::decode_cfg(
                               raw_bytes, &RangeCfg::new(0..=65536)
                           ) {
                               Ok(m) => m,
                               Err(e) => {
                                   tracing::warn!("Failed to decode P2P message: {:?}", e);
                                   continue;
                               }
                           };

                           // BCAST-02: Deduplication by digest.
                           // Compute digest and skip if already seen.
                           let digest = p2p_msg.digest();
                           if seen_digests.contains(&digest) {
                               tracing::trace!("Duplicate message filtered by digest");
                               continue;
                           }
                           // Bound the set: if at capacity, clear oldest half.
                           // (A simple strategy; production could use LRU.)
                           if seen_digests.len() >= MAX_SEEN_DIGESTS {
                               seen_digests.clear();
                               tracing::debug!("Cleared seen_digests set (reached {} capacity)", MAX_SEEN_DIGESTS);
                           }
                           seen_digests.insert(digest);

                           // Service filtering (BCAST-05)
                           if !service_router.should_accept(&p2p_msg) {
                               tracing::trace!("Filtered message for unsubscribed service");
                               continue;
                           }

                           // Deserialize and forward to Aggregator
                           match p2p_msg.to_submission() {
                               Ok((_service_id, submission)) => {
                                   let peer_id = const_hex::encode(peer_pubkey.as_ref());
                                   if let Err(e) = aggregator_tx.send(AggregatorCommand::Receive {
                                       submission,
                                       peer: Peer::Other(peer_id),
                                   }) {
                                       tracing::error!("Failed to forward to aggregator: {:?}", e);
                                   }
                               }
                               Err(e) => {
                                   tracing::warn!("Failed to deserialize submission: {:?}", e);
                               }
                           }
                       }
                       None => {
                           tracing::error!("Inbound bridge channel closed");
                           break;
                       }
                   }
               }
           }
       }
       ```

You MUST encode the message to `Vec<u8>` before sending on the direct channel. Use `commonware_codec::Encode::encode(&msg)` which auto-derives from the `Write + EncodeSize` traits already implemented on `P2pMessage` in Plan 01.

       ```rust
       match P2pMessage::from_submission(&service_id, &*submission) {
           Ok(msg) => {
               // Broadcast via Engine channel (for caching + catch-up / CATCH-01)
               let ack_rx = mailbox.broadcast(Recipients::All, msg.clone()).await;

               // CRITICAL: Encode P2pMessage to bytes before sending on direct channel.
               // direct_sender.send() requires bytes (impl Into<IoBufs>), not P2pMessage.
               // Encode::encode() is auto-derived from Write + EncodeSize on P2pMessage.
               let encoded_bytes: Vec<u8> = commonware_codec::Encode::encode(&msg);
               direct_sender.send(Recipients::All, encoded_bytes, false).await;

               // Check Engine broadcast acknowledgment
               match ack_rx.recv().await {
                   Some(recipients) if recipients.is_empty() => {
                       retry_queue.push(msg);
                       tracing::warn!("No peers received broadcast, queued for retry");
                   }
                   Some(recipients) => {
                       tracing::debug!("Broadcast delivered to {} peers", recipients.len());
                       // Flush retry queue since peers are available
                       if !retry_queue.is_empty() {
                           let queued = retry_queue.drain_all();
                           for queued_msg in queued {
                               let _ = mailbox.broadcast(Recipients::All, queued_msg.clone()).await;
                               // Encode each queued message to bytes for direct channel too
                               let queued_bytes: Vec<u8> = commonware_codec::Encode::encode(&queued_msg);
                               direct_sender.send(Recipients::All, queued_bytes, false).await;
                           }
                       }
                   }
                   None => {
                       tracing::error!("Broadcast engine shut down");
                   }
               }
           }
           Err(e) => {
               tracing::error!("Failed to create P2pMessage: {:?}", e);
           }
       }
       ```
