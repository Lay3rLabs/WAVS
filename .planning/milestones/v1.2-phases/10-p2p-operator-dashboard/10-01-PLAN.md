**2. Tauri command (`app/src-tauri/src/commands.rs`):**
Update `cmd_get_p2p_status` to also accept `WavsConfigState` and populate the `discovery_mode` field. The function should:
- Add `wavs_config: State<'_, WavsConfigState>` parameter
- Get the P2P status from the dispatcher as before
- Read the P2pConfig variant from `wavs_config.get_cloned()` and match on it:
  - `P2pConfig::Disabled` => `"disabled"`
  - `P2pConfig::Local { .. }` => `"local"`
  - `P2pConfig::Remote { .. }` => `"remote"`
- If config is None, default to `"unknown"`
- Set `status.discovery_mode = mode.to_string()` before returning

```rust
#[tauri::command(rename_all = "snake_case")]
pub async fn cmd_get_p2p_status(
    wavs_instance: State<'_, WavsInstanceState>,
    wavs_config: State<'_, WavsConfigState>,
) -> AppResult<wavs_types::P2pStatus> {
    let dispatcher = wavs_instance.dispatcher()?;
    let mut status = dispatcher.aggregator.get_p2p_status().await;

    let mode = match wavs_config.get_cloned() {
        Some(config) => match config.p2p {
            wavs::subsystems::aggregator::p2p::P2pConfig::Disabled => "disabled",
            wavs::subsystems::aggregator::p2p::P2pConfig::Local { .. } => "local",
            wavs::subsystems::aggregator::p2p::P2pConfig::Remote { .. } => "remote",
        },
        None => "unknown",
    };
    status.discovery_mode = mode.to_string();

    Ok(status)
}
```

Note: Check how other commands import `P2pConfig` -- the path may need adjustment. Look at existing `use` statements for the correct module path. The `wavs_config.get_cloned()` method returns `Option<Config>`.
