## Design System

| Property | Value |
|----------|-------|

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`, `py-1`) | Mnemonic word grid gaps, balance row vertical padding, inline spacing, sidebar nav item gaps |
| sm | 8px (`gap-2`, `p-2`, `py-2`) | Button gaps, form row gaps, inner container padding, sidebar nav item vertical padding |
| sm-md | 12px (`gap-3`, `p-3`, `px-3`) | Sidebar nav item horizontal padding, compact input horizontal padding, destructive confirmation panel padding. Justified: 12px is 3x4 and serves as a touch-target intermediate between 8px and 16px for interactive elements that need comfortable hit areas without full card-level padding. |
| md | 16px (`gap-4`, `p-4`, `px-4`) | Card padding, section internal gaps, standard element spacing, primary input horizontal padding |
| lg | 24px (`gap-6`, `p-6`) | Section-to-section gap in scrollable content, sidebar-to-content gap |
| xl | 32px (`gap-8`, `px-8`) | Header horizontal padding, page-level horizontal padding |

Exceptions: none -- all values are multiples of 4.

## Typography

| Role | Size | Weight | Line Height | Tailwind Class | Usage |
|------|------|--------|-------------|----------------|-------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm` | Section descriptions, form labels, inline text |
| Label | 12px | 400 (regular) | 1.5 | `text-xs` | Field labels, helper text, status indicators, balance values |
| Heading | 18px | 600 (semibold) | 1.2 | `text-lg font-semibold` | Section card headings (Wallet, WAVS Home, etc.) |
| Error | 14px | 400 (regular) | 1.5 | `text-sm` | Error messages within sections |

**Font family:** Montserrat sans-serif for all text. Monospace (`font-mono`) for addresses, paths, hex values, code snippets, and TOML content.

**Constraints:**
- Maximum 2 weights used in this phase: 400 (regular) and 600 (semibold)
- Weight 700 (bold) is loaded but NOT used in Settings -- reserved for other pages
- No `text-base` (16px) in Settings section content; `text-sm` (14px) is the body standard for this dense settings layout
- Sidebar nav labels use `text-sm` (14px) at weight 400

**Primary focal point:** Active sidebar item and the section heading of the visible card. When visible, the restart banner takes visual priority over both (red CTA draws the eye first).

## Destructive Action Pattern

Both destructive actions (Reset Wallet, Clear Services) follow the same interaction pattern:

1. **Trigger:** Red outline button (`color="red" variant="outline"`)
2. **Confirmation panel:** Replaces the trigger button with a bordered panel
   - Background: `bg-charcoal-darkest`
   - Border: `border border-red-2` (#814B56)
   - Padding: `p-3` (12px)
   - Border radius: `rounded`
   - Warning text: `text-sm text-red-4` (#C38D99)
3. **Actions:** Two buttons in a `flex gap-3` row
   - Cancel: `variant="outline"` (neutral) -- label is context-specific (see Copywriting Contract)
   - Confirm: `color="red"` (solid red)
4. **Loading state:** Confirm button text changes (e.g., "Resetting...") with `disabled` prop

## Phase-Specific Notes

### What This Phase Does NOT Have

- No new pages or routes
- No new user-facing features
- No new icons
- No new animations
- No new color tokens
- No responsive breakpoints (Tauri desktop app, fixed viewport)
- No dark/light mode toggle (always dark)
- No accessibility audit changes (existing patterns preserved as-is)

### What This Phase Polishes

- **Consistency:** All 6 section cards use identical padding, border, radius, and heading styles
- **Hierarchy:** Sidebar nav provides clear section-level navigation
- **Spacing:** Standardize on `gap-4` inside cards, `gap-6` between cards
- **Typography:** All headings use `text-lg font-semibold text-beige-light`, all descriptions use `text-sm text-tan-muted`

### Cross-Section State (Lifted to Parent)

Only ONE piece of state crosses section boundaries:
- `changed: boolean` -- whether settings requiring a restart have been modified
- Sections that can set it: WavsHomeSection, TomlEditorSection
- Passed as `onChanged: () => void` callback prop

All other state (30+ useState hooks) is section-local.
