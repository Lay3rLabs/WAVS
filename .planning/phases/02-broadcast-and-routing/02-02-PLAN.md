  <action>
    This task modifies `run_lookup_network()` and `run_discovery_network()` to:
    - Register TWO channels (channel 0 for broadcast Engine, channel 1 for direct inbound)
    - Create and start the broadcast Engine with the Engine channel
    - Handle all P2pCommand variants in the bridge loop
    - Read inbound messages from the direct channel and forward to Aggregator via aggregator_tx
    - Use ServiceRouter for filtering and RetryQueue for failed publishes

    **CRITICAL ARCHITECTURE:** Use the Two-Channel approach (Option A from research):
    - Channel 0 (engine_sender, engine_receiver): consumed by `Engine::start()` for caching + catch-up
    - Channel 1 (direct_sender, direct_receiver): read in bridge loop for real-time inbound forwarding

    On outbound (Publish): broadcast via Mailbox on Engine channel AND send directly on Channel 1.
    On inbound: Channel 1 delivers to bridge loop -> ServiceRouter filter -> AggregatorCommand::Receive.

    **Step-by-step changes to run_lookup_network():**

    1. Add `aggregator_tx: crossbeam::channel::Sender<AggregatorCommand>` as a new parameter (after command_rx). This is needed to forward inbound messages to the Aggregator.

    2. Change channel registration from one to two channels. Replace:
       ```rust
       let (_sender, _receiver) = network.register(0u64, Quota::per_second(NZU32!(100)), 1024);
       ```
       With:
       ```rust
       // Channel 0: for broadcast Engine (caching + catch-up)
       let (engine_sender, engine_receiver) = network.register(
           0u64, Quota::per_second(NZU32!(100)), 1024,
       );
       // Channel 1: for direct message forwarding to Aggregator
       let (direct_sender, mut direct_receiver) = network.register(
           1u64, Quota::per_second(NZU32!(100)), 1024,
       );
       ```

    3. Create the broadcast Engine AFTER channel registration, BEFORE network.start():
       ```rust
       use commonware_broadcast::buffered::{Config as BroadcastConfig, Engine, Mailbox};

       let broadcast_config = BroadcastConfig {
           public_key: own_pubkey.clone(),
           mailbox_size: 256,
           deque_size: 128,  // CATCH-02: bounded message storage per peer
           priority: false,
           codec_config: RangeCfg::new(0..=65536),
           peer_provider: oracle.clone(),
       };
       let (engine, mailbox) = Engine::<_, _, P2pMessage, _>::new(
           context.with_label("p2p_broadcast"),
           broadcast_config,
       );
       ```
       NOTE: If `oracle.clone()` does not compile (Oracle may not implement Clone), wrap the oracle in `Arc` or investigate the Oracle API. The research notes this as an open question. If Oracle does not Clone, create a second Oracle reference or use Arc<Mutex<Oracle>>. Alternatively, if the BroadcastConfig's peer_provider needs ownership, create the Engine's config before setting up the oracle tracking (track(0, ...) can happen after Engine creation since Engine uses the provider reference).

    4. Start the network, then start the Engine:
       ```rust
       let _net_handle = network.start();
       let _engine_handle = engine.start((engine_sender, engine_receiver));
       ```

    5. Replace the bridge loop with a `tokio::select!` loop that handles BOTH command_rx AND direct_receiver:
       ```rust
       let mut service_router = ServiceRouter::new();
       let mut retry_queue = RetryQueue::new();

       loop {
           tokio::select! {
               cmd = command_rx.recv() => {
                   match cmd {
                       Some(P2pCommand::Publish { service_id, submission }) => {
                           match P2pMessage::from_submission(&service_id, &*submission) {
                               Ok(msg) => {
                                   // Broadcast via Engine channel (for caching + catch-up)
                                   let ack_rx = mailbox.broadcast(Recipients::All, msg.clone()).await;
                                   // Also send on direct channel for real-time delivery
                                   direct_sender.send(Recipients::All, msg.clone(), false).await;

                                   // Check Engine broadcast acknowledgment
                                   match ack_rx.recv().await {
                                       Some(recipients) if recipients.is_empty() => {
                                           retry_queue.push(msg);
                                           tracing::warn!("No peers received broadcast, queued for retry");
                                       }
                                       Some(recipients) => {
                                           tracing::debug!("Broadcast delivered to {} peers", recipients.len());
                                           // Flush retry queue since peers are available
                                           if !retry_queue.is_empty() {
                                               let queued = retry_queue.drain_all();
                                               for queued_msg in queued {
                                                   let _ = mailbox.broadcast(Recipients::All, queued_msg.clone()).await;
                                                   direct_sender.send(Recipients::All, queued_msg, false).await;
                                               }
                                           }
                                       }
                                       None => {
                                           tracing::error!("Broadcast engine shut down");
                                       }
                                   }
                               }
                               Err(e) => {
                                   tracing::error!("Failed to create P2pMessage: {:?}", e);
                               }
                           }
                       }
                       Some(P2pCommand::Subscribe { service_id }) => {
                           service_router.subscribe(&service_id);
                           tracing::info!("Subscribed to service: {}", service_id);
                       }
                       Some(P2pCommand::Unsubscribe { service_id }) => {
                           service_router.unsubscribe(&service_id);
                           tracing::info!("Unsubscribed from service: {}", service_id);
                       }
                       Some(P2pCommand::GetStatus { response_tx }) => {
                           let status = P2pStatus {
                               enabled: true,
                               local_peer_id: Some(const_hex::encode(own_pubkey.as_ref())),
                               listen_addresses: vec![listen_addr.to_string()],
                               external_addresses: vec![],
                               connected_peers: 0, // Phase 3 fills from network state
                               peer_ids: vec![],
                               subscribed_topics: service_router.subscribed_topics(),
                               topic_peer_counts: Default::default(),
                           };
                           let _ = response_tx.send(status);
                       }
                       Some(P2pCommand::BlockPeer { pubkey_hex }) => {
                           match parse_authorized_peers(&[pubkey_hex.clone()]) {
                               Ok(keys) if !keys.is_empty() => {
                                   oracle.block(keys[0].clone()).await;
                                   tracing::info!("Blocked peer: {}", pubkey_hex);
                               }
                               _ => {
                                   tracing::error!("Failed to parse pubkey for blocking: {}", pubkey_hex);
                               }
                           }
                       }
                       None => {
                           tracing::info!("P2P command channel closed, shutting down");
                           context.stop(0, None).await.ok();
                           break;
                       }
                   }
               }
               msg = direct_receiver.recv() => {
                   match msg {
                       Ok((peer_pubkey, raw_bytes)) => {
                           // Decode P2pMessage from raw bytes
                           let p2p_msg: P2pMessage = match commonware_codec::Decode::decode_cfg(
                               raw_bytes, &RangeCfg::new(0..=65536)
                           ) {
                               Ok(m) => m,
                               Err(e) => {
                                   tracing::warn!("Failed to decode P2P message: {:?}", e);
                                   continue;
                               }
                           };

                           // Service filtering (BCAST-05)
                           if !service_router.should_accept(&p2p_msg) {
                               tracing::trace!("Filtered message for unsubscribed service");
                               continue;
                           }

                           // Deserialize and forward to Aggregator
                           match p2p_msg.to_submission() {
                               Ok((_service_id, submission)) => {
                                   let peer_id = const_hex::encode(peer_pubkey.as_ref());
                                   if let Err(e) = aggregator_tx.send(AggregatorCommand::Receive {
                                       submission,
                                       peer: Peer::Other(peer_id),
                                   }) {
                                       tracing::error!("Failed to forward to aggregator: {:?}", e);
                                   }
                               }
                               Err(e) => {
                                   tracing::warn!("Failed to deserialize submission: {:?}", e);
                               }
                           }
                       }
                       Err(e) => {
                           tracing::error!("Direct receiver error: {:?}", e);
                           break;
                       }
                   }
               }
           }
       }
       ```
