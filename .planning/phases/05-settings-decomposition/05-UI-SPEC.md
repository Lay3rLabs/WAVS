## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (e.g. `gap-1`, `py-1`) |
| sm | 8px | Compact element spacing (e.g. `gap-2`, `p-2`) |
| md | 16px | Default element spacing (e.g. `gap-4`, `p-4`) |
| lg | 24px | Section padding (e.g. `gap-6`) |
| xl | 32px | Layout gaps (e.g. `gap-8`) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Sidebar width: fixed 200px (not on scale — structural layout value from CONTEXT.md)

## Interaction Contract

### Sidebar Navigation
- Click behavior: instant section swap, no animation (CONTEXT.md decision)
- Active section: tracked via `useState<SectionKey>` in parent Settings component, default `'wallet'`
- Section keys: `'wallet' | 'node' | 'environment' | 'agent' | 'mcp' | 'reset'`
- No URL hash, no deep-linking (CONTEXT.md decision)

### Unsaved Changes Banner
- Visibility: controlled by `hasUnsavedChanges` prop passed from parent to each section; sections call `onChangeDetected()` callback when local state diverges from saved state
- Position: above the sidebar+content split (fixed, always visible regardless of active section)
- "Restart Application" button: `color="red"` variant, calls existing `handleRestart` handler

### OAuth Flow (Agent section)
- OAuth listener stays in parent Settings component (not in AgentSection)
- AgentSection receives `onOAuthComplete` callback prop
- Navigating between sidebar sections does not unmount the parent — listener persists

### Destructive Actions (Reset section)
- "Clear All Services & Registries": shows inline confirmation panel on first click (matches existing pattern at line 1185-1213)
- Confirmation panel: `bg-charcoal-darkest border border-red-2` rounded, contains warning text + "Confirm Clear" / "Keep Services" buttons
- No modal overlay — inline expansion only (preserves existing UX pattern)
- Reset section sidebar item: same visual style as other items, no special warning color (CONTEXT.md decision)
