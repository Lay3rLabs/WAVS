**1. BLS operator registration in service_managers.rs** (`register_operators` method):

The existing `register_operators` method in `ServiceManagers` currently:
1. Gets `SignerResponse` from each WAVS instance
2. Matches on `SignerResponse::Secp256k1` to get evm_address and hd_index
3. Derives signing key from mnemonic + hd_index
4. Creates `AvsOperator::with_keys(operator, signer, operator_key, signing_key)`
5. Calls `manager.configure(&config)` via `EvmMiddleware`

For BLS tests (`test.bls == true`), the flow must change:
1. Gets `SignerResponse::Bls12381 { hd_index, g1_pubkey_hex }` from WAVS
2. Derives BLS key from operator mnemonic + `wavs_signer_hd_index` using `utils::bls_signing::derive_bls_key`
3. Gets G1 pubkey bytes (128 bytes) from the BLS key using `utils::bls_signing::bls_g1_pubkey_bytes`
4. Creates proof-of-possession by signing `keccak256(abi.encode(operator_address))`:
   ```rust
   let encoded_addr = alloy_sol_types::sol_data::Address::abi_encode(&operator_address);
   let message = alloy_primitives::keccak256(&encoded_addr);
   let g2_sig = utils::bls_signing::bls_sign_digest(&bls_secret, message.as_slice()).unwrap();
   let g2_proof_bytes = utils::bls_signing::bls_g2_signature_bytes(&g2_sig);
   ```
5. Creates `AvsOperator::with_bls_keys(operator_address, operator_key_hex, g1_pubkey_bytes, g2_proof_bytes)`

IMPORTANT: The keccak256(abi.encode(operator_address)) must match the Solidity contract's expectation. In Solidity, `abi.encode(address)` left-pads the address to 32 bytes. Use `alloy_sol_types::sol_data::Address::abi_encode(&operator_address)`.

Update the match on `signer_resp` to branch on `test.bls`:
```rust
if test.bls {
    match signer_resp {
        SignerResponse::Bls12381 { hd_index, g1_pubkey_hex: _ } => {
            let wavs_signer_hd_index = hd_index;
            let operator_hd_index = (test_index * MULTI_OPERATOR_COUNT + operator_offset) as u32;
            let operator_mnemonic = &self.configs.mnemonics.operators[operator_offset];
            let operator_signer = utils::evm_client::signing::make_signer(operator_mnemonic, Some(operator_hd_index)).unwrap();
            let operator_address = operator_signer.address();
            let operator_private_key = const_hex::encode(operator_signer.to_bytes());

            // Derive BLS key from operator mnemonic + WAVS HD index
            let bls_secret = utils::bls_signing::derive_bls_key(operator_mnemonic, wavs_signer_hd_index).unwrap();
            let g1_pubkey_bytes = utils::bls_signing::bls_g1_pubkey_bytes(&bls_secret);

            // Create proof-of-possession: BLS sign keccak256(abi.encode(operator_address))
            let encoded_addr = alloy_sol_types::sol_data::Address::abi_encode(&operator_address);
            let message = alloy_primitives::keccak256(&encoded_addr);
            let g2_sig = utils::bls_signing::bls_sign_digest(&bls_secret, message.as_slice()).unwrap();
            let g2_proof_bytes = utils::bls_signing::bls_g2_signature_bytes(&g2_sig);

            AvsOperator::with_bls_keys(operator_address, operator_private_key, g1_pubkey_bytes, g2_proof_bytes)
        }
        _ => panic!("Expected Bls12381 SignerResponse for BLS test, got Secp256k1"),
    }
} else {
    // Existing secp256k1 path -- keep completely unchanged
}
```
