# Phase 11 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — manual Tailwind CSS |
| Preset | not applicable |
| Component library | custom atoms (Button, Tabs, Expander, Breadcrumb, AddressDisplay, Toast, Modal) |
| Icon library | none — unicode glyphs used inline (▼ ▶) |
| Font | Montserrat (400, 600, 700) via Google Fonts |

No shadcn. Project uses a hand-rolled Tailwind component system with a custom warm-dark color palette. All new components must use the same pattern.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding (px-1.5 py-0.5) |
| sm | 8px | Compact element spacing, gap between inline items |
| md | 16px | Default element spacing, card internal padding (p-4) |
| lg | 24px | Section padding, gap between major card sections |
| xl | 32px | Layout gaps between page regions |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (not used in detail pages) |

Exceptions:
- Tab underline offset: `-mb-px` (1px) — existing Tabs.tsx pattern, do not change
- Scrollbar width: 8px — global CSS, not modified by this phase

## Typography

Tailwind text scale maps to these concrete sizes. Match the existing codebase usage exactly.

| Role | Tailwind Class | Size | Weight | Line Height |
|------|---------------|------|--------|-------------|
| Body | `text-sm` | 14px | 400 (regular) | 1.5 (Tailwind default) |
| Label / meta | `text-xs` | 12px | 500 (medium) | 1.5 |
| Heading (section) | `text-base` | 16px | 500 (medium) | 1.25 |
| Page title | `text-2xl` | 24px | 600 (semibold) | 1.2 |

Source: derived from `ComponentsPage.tsx` (`text-2xl font-semibold` for h1), `ServiceDetailPage.tsx` (`text-xl font-semibold` for entity names), and pattern throughout codebase for `text-sm`, `text-xs` metadata labels.

Note: The component detail page header uses `text-xl font-semibold` (20px / 600) to match `ServiceDetailPage` — this sits between Heading and Page title roles and is intentional parity with that pattern.

## Color

All colors are from `tailwind.config.js`. No new color values are introduced in this phase.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `charcoal-darkest` | #1E1E1E | Page background (body) |
| Secondary (30%) | `charcoal-medium` | #2D2A2A | Cards, header section, tab content areas |
| Card border | `charcoal-light` | #383232 | Border on all card/section containers |
| Body text | `beige-warm` | #CEC3B7 | Primary readable content, field values |
| Muted text | `tan-muted` | #A89F96 | Labels, metadata, empty state copy |
| Accent (10%) | `purple-1` / `purple-2` | #4A345D / #62497B | Active tab underline, "used by" service link hover border, any clickable purple-tinted interactive element |
| Destructive | `red-2` / `red-3` | #814B56 / #A7656F | Destructive button (none in this phase — read-only page) |
| Mono / code | `beige-warm` + `font-mono` | #CEC3B7 | Digest, package name, config keys, env var keys, JSON Schema values |

Accent reserved for:
- Active tab underline border (`border-purple-2`)
- Service link hover border on "used by" chips (`hover:border-purple-1`)
- Any future interactive navigation elements that link away from the page

Source types get neutral `bg-charcoal-light text-beige-warm` badges — not accent-colored. Accent is strictly navigation/active-state only.

## Layout Contract

### Page Structure

```
<Breadcrumb items={[{ label: "Components", to: "/components" }, { label: shortDigest }]} />

<div class="flex flex-col gap-6">
  <!-- Header card -->
  <div class="p-4 rounded-lg bg-charcoal-medium border border-charcoal-light">
    <!-- Title row: component name/digest + source badge + "used by" chips -->
    <!-- Info grid: digest (full, copyable), source URI/package, services using it -->
  </div>

  <!-- Tab bar -->
  <Tabs tabs={[Interface, Permissions, Configuration]} />

  <!-- Tab content -->
  <div> ... </div>
</div>
```

### Header Card Contents (source: CONTEXT.md decisions)

Row 1 (title):
- Component identifier: short digest as title (`text-xl font-semibold text-beige-light`)
- Source-type badge: `px-1.5 py-0.5 text-xs font-medium bg-charcoal-light text-beige-warm rounded` — values: "Registry" | "Download" | "Digest"

Row 2 (info grid — `grid grid-cols-2 gap-3 text-sm`):
- Digest: label `text-tan-muted text-xs font-medium` + `<AddressDisplay address={digest} full />`
- Source URI / Package: label + `font-mono text-beige-warm`
- OCI URI (if applicable): label + monospace value with copy

Row 3 ("Used by" services — `border-t border-charcoal-light pt-3`):
- Label: `text-tan-muted text-xs font-medium` — "Used by N services"
- Service links: `px-2 py-1 text-xs bg-charcoal-light hover:bg-charcoal-dark border border-charcoal-light hover:border-purple-1 text-beige-warm rounded transition-colors` — clicking navigates to `/services/:chainId/:address`

### Three Tabs

| Tab key | Label | Content |
|---------|-------|---------|
| `interface` | Interface | Exported function list — accordion per function |
| `permissions` | Permissions | HTTP hosts, filesystem, sockets, DNS + resource limits |
| `configuration` | Configuration | Config keys + env var keys |

Default active tab: `interface`

### Interface Tab — Accordion Pattern

Each exported function rendered as an `<Expander>` (existing atom):
- Label: function name in `font-mono text-beige-warm` + doc comment summary if present (`text-tan-muted text-xs`)
- Expanded content: two sub-sections (Input Schema / Output Schema), each displaying a formatted JSON tree

JSON Schema tree display:
- Background: `bg-charcoal-dark p-3 rounded`
- Text: `text-beige-light text-xs font-mono whitespace-pre-wrap`
- Type annotations: `text-tan-muted` — de-emphasized relative to field names
- Section heading: `text-tan-muted text-xs font-medium mb-2` ("Input Schema" / "Output Schema")

### Permissions Tab — Grid Pattern

Reuse `PermRow` pattern from `ServiceDetailPage.tsx`:
```
<div class="flex items-center gap-2">
  <span class="text-tan-muted">{label}:</span>
  <span class="text-beige-warm">{value}</span>
</div>
```

Sections (each with `border-t border-charcoal-light pt-2 mt-1` separator except the first):
1. Network: HTTP Hosts, DNS Resolution, Raw Sockets
2. Storage: File System access
3. Resource Limits: Fuel Limit (formatted with `toLocaleString()`), Time Limit (formatted as `{N}s`)

Boolean values displayed as "yes" / "no" (not true/false).
HTTP hosts "all" displayed as "all (unrestricted)" to clarify security implication.
HTTP hosts "none" displayed as "none".
HTTP hosts list displayed as comma-separated host strings.

### Configuration Tab — Tag Cloud Pattern

Two sections with `border-t border-charcoal-light pt-2 mt-1` between them:

Config Keys section:
- Heading: `text-tan-muted text-xs font-medium mb-2` — "Config Keys"
- Each key: `px-1.5 py-0.5 text-xs bg-charcoal-light text-beige-warm rounded font-mono`
- Wrapped in `flex flex-wrap gap-1`

Env Vars section:
- Heading: `text-tan-muted text-xs font-medium mb-2` — "Environment Variables"
- Each key: same tag style as config keys
- Wrapped in `flex flex-wrap gap-1`

## States Contract

### Loading State

Skeleton placeholders matching final layout structure:
- Header card: full-width block `h-24 bg-charcoal-medium rounded-lg animate-pulse`
- Tab bar: three tab-width blocks `h-8 bg-charcoal-light rounded animate-pulse` in a row
- Tab content: 3 stacked `h-16 bg-charcoal-medium rounded animate-pulse` blocks

No spinner. Pulse animation only. Do not show partial data.

### Component Not Found State (CONTEXT.md — locked)

Full-page message inside the main layout:
```
<div class="flex flex-col gap-4">
  <p class="text-tan-muted">Component not found for {digest}</p>
  <Button text="Back to Components" size="sm" onClick={() => navigate('/components')} />
</div>
```

### Empty Interface Tab

When a component has zero exported functions:
```
<p class="text-tan-muted italic text-sm">No exported functions found for this component.</p>
```

### Empty Configuration Tab

When config keys and env vars are both empty:
```
<p class="text-tan-muted italic text-sm">This component declares no config keys or environment variables.</p>
```

### Error (data fetch failure)

Use `Toast.error(message)` — existing global toast system. Do not block the page. Show whatever partial data loaded successfully.

Error message format: "Failed to load component schema: {reason}" and "Failed to load component metadata: {reason}" as separate toasts if the respective commands fail independently.

## Interaction Contract

### Navigation

- Route: `/components/:digest`
- Entry point: clicking a component card on `ComponentsPage` (Phase 12 wires this up; detail page itself just reads `useParams`)
- Back: browser back button + Breadcrumb "Components" link to `/components`

### Accordion (Expander atom)

- Collapsed by default — `defaultExpanded={false}`
- Click anywhere on the label row toggles open/closed
- Only one function can be open at a time — OR all can be open simultaneously (user controlled, no forced single-open constraint)
- Scroll behavior: no auto-scroll on open; user scrolls manually

### Digest Copy

- Use existing `<AddressDisplay>` atom which already handles copy-to-clipboard
- No additional copy affordance needed

### Service Link Chips ("Used by")

- Click navigates to `/services/{chain}/{address}`
- Hover: `hover:border-purple-1` border flash (matches existing ComponentsPage chip pattern)
- No tooltip required

### Tab Switching

- Use existing `Tabs` atom — no modification
- Tab state is local component state (`useState`) — not persisted to URL or store
